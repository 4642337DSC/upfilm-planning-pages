# upfilm-planning-pages

Gated content-planning pages, one per client, rendered by the
`content-plan` Claude Code skill (`content-plan` Step 10 in
`4642337DSC/claude-client-bibles`). **Private and must stay private** —
this is internal planning commentary (angle rationale, dropped ideas,
performance notes), not client-facing content. Do not fork, mirror, or
make public.

## Layout

```
clients/<slug>/plan/index.html
```

Each file is a self-contained static HTML page — no build step, no
dependencies. Regenerated by re-running content-plan's publish step;
never hand-edited.
